Week 2 reveal.js

1. start.bat をダブルクリックしてください。
2. ブラウザで http://localhost:8000/week2.html が開きます。
3. slides/2_multiple_regression.md を編集するとスライド内容を変更できます。
4. images/multiple_regression/ の画像は Markdown から既存パスのまま参照されます。
